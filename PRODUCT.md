# Funding Wire
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
The Möbius owner wants to follow startup funding like Seb Johnson's posts.
## Product Purpose
Worldwide source-linked funding news: company, amount, round, disclosed investors, publication date; search, filters, saved companies.
## Capabilities and Constraints
Owner selected worldwide rather than UK/Europe coverage. Use public sources without a paid data subscription. Coverage is uneven, not exhaustive. Unknown details must stay unknown. Keep reported round amounts distinct from valuations and investor cheque sizes.
## Operating Context
Personal Möbius mini-app, phone-first. Platform supplies React, theming and private saved data. No changes to the shell.
## Open decisions
No specific visual preference supplied; use the existing Möbius design system and a compact reading-focused feed. Periodic refresh cadence is an implementation default, not a claimed preference.
